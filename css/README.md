Urban Style Website

Project Description

Urban Style is an online clothing store website. It allows customers to view clothing products, search for products and add items to a shopping cart.

Website Pages

* Home
* Products
* About Us
* Contact Us

Features

* Product search and filtering.
* Shopping cart.
* Add and remove products.
* Change product quantities.
* Cart information saved using local storage.
* Contact and enquiry forms with JavaScript validation.
* Responsive website layout.

Technologies i used

* HTML
* CSS
* JavaScript
* Visual Studio Code
